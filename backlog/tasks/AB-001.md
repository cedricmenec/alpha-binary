# AB-001 | Préparer le dépôt Greenfield et les prérequis ASF

État : À faire  
Priorité : P1  
Ordre : 1  
Dépendances : aucune  
Type : bootstrap non payant, à réaliser avant tout run ASF

## Objectif

Préparer les prérequis minimaux du dépôt initialisé pour permettre le premier changement produit piloté par OpenSpec dans ASF V1.

## Critères d'acceptation

- Une configuration OpenSpec adaptée au projet existe dans `openspec/config.yaml` et l'initialisation de l'outillage est reproductible.
- Un manifeste Node.js et son lock sont présents, sans dépendance ni framework ajouté sans besoin.
- `npm run check` exécute des contrôles réels adaptés au contenu du dépôt et réussit.
- La CI indépendante appelle ce contrôle sans lancer de phase LLM.
- Les fichiers ASF gérés existants restent conformes à leur lock.

## Contraintes

- Préparer le bootstrap sans invocation OpenCode/OpenRouter payante.
- Ne pas créer d'application, de tests métier ou de décisions produit fictifs.
- Ne toucher ni aux secrets ni aux réglages administratifs GitHub.

## Sources

Cadrage Greenfield AlphaBinary et note « Prérequis au premier run ASF » de la page projet Notion. La contrainte d'exécution est vérifiable dans `.asf/agentkit/runtime/request.mjs` et `.asf/agentkit/runtime/phase.sh`.
