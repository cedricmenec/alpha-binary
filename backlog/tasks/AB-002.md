# AB-002 | Poser la structure Node.js Core et CLI

État : À faire  
Priorité : P1  
Ordre : 2  
Dépendances : AB-001

## Objectif

Créer le squelette minimal de l'outil en séparant les traitements réutilisables de l'interface en ligne de commande.

## Critères d'acceptation

- Le dépôt contient un Core appelable indépendamment de la CLI.
- La CLI dispose d'un point d'entrée exécutable localement depuis les sources et d'une aide concise.
- L'organisation permet de tester Core et CLI avec les commandes existantes du dépôt.
- La solution n'exige pas la publication du package sur npm.

## Contraintes

- Utiliser Node.js et garder une structure simple.
- Le choix JavaScript ou TypeScript et l'outillage restent proportionnés au besoin.
- N'ajouter ni API, SDK, serveur ni architecture de plugins.

## Sources

Architecture minimale et exécution depuis GitHub décrites dans le cadrage AlphaBinary Notion.
